# Getting Started with Model Context Protocol (MCP)

The **Model Context Protocol (MCP)** is an open standard by **Anthropic** that enables seamless, secure, and structured interactions between large language models (LLMs) and external tools, data sources, and APIs. It provides a well-defined interface for extending the capabilities of AI assistants like Claude by allowing them to read, write, and act on user data in a controlled and auditable manner.

## Why MCP Matters

AI models typically operate as black boxes, unable to interact meaningfully with personal data or tools without bespoke integrations. MCP solves this by acting as a **unified, secure middleware layer**.

### Key Benefits:
- ✅ **Standardized Communication** between AI models and external systems
- 🔐 **Secure and Permissioned Access** to tools and data
- 🧩 **Modular Tooling and Resource Sharing**
- 🔄 **Reusability Across AI Platforms** that support MCP

## How MCP Works

MCP defines a **bidirectional communication protocol** with:
- A **Server**, which exposes tools/resources (e.g., files, databases)
- A **Client**, typically an AI assistant (e.g., Claude Desktop)
- A structured **Protocol** that governs how tools are listed, invoked, and resources read

### Communication Flow
1. The server registers tools and resources
2. The model requests available tools/resources
3. It makes structured calls (e.g., `call_tool`, `read_resource`)
4. Server returns results or errors

## Build Your First MCP Server

Here’s a basic example that lets Claude access a local text file:

```python
from mcp import Server
import mcp.server.stdio

server = Server("my-first-server")

@server.list_resources()
async def list_files():
    return [
        {
            "uri": "file://notes.txt",
            "name": "My Notes",
            "description": "Personal notes file"
        }
    ]

@server.read_resource()
async def read_file(uri: str):
    if uri == "file://notes.txt":
        return "These are my important notes!"
    raise ValueError("File not found")

if __name__ == "__main__":
    import asyncio
    asyncio.run(mcp.server.stdio.stdio_server().run(server))
```

## Adding Interactive Tools

MCP lets you define actionable tools that AI can use:

```python
@server.list_tools()
async def list_tools():
    return [
        {
            "name": "add_task",
            "description": "Add a task to my todo list",
            "inputSchema": {
                "type": "object",
                "properties": {
                    "task": {"type": "string", "description": "Task description"}
                },
                "required": ["task"]
            }
        }
    ]

@server.call_tool()
async def call_tool(name: str, arguments: dict):
    if name == "add_task":
        task = arguments["task"]
        with open("tasks.txt", "a") as f:
            f.write(f"- {task}\n")
        return f"Task added: {task}"
```

## Claude Desktop Integration

Configure Claude Desktop to connect with your MCP server by modifying its config file:

```json
{
  "mcpServers": {
    "my-server": {
      "command": "python",
      "args": ["path/to/server.py"]
    }
  }
}
```

- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%/Claude/claude_desktop_config.json`

## Real-World Use Case: Database Tooling

```python
import sqlite3
from mcp import Server

server = Server("db-server")

@server.list_tools()
async def list_db_tools():
    return [
        {
            "name": "query_customers",
            "description": "Search customer info",
            "inputSchema": {
                "type": "object",
                "properties": {
                    "search": {"type": "string"}
                }
            }
        }
    ]

@server.call_tool()
async def query_customers(name, arguments):
    if name == "query_customers":
        term = arguments.get("search", "")
        conn = sqlite3.connect("customers.db")
        cursor = conn.cursor()
        cursor.execute("SELECT name, email FROM customers WHERE name LIKE ?", (f"%{term}%",))
        results = cursor.fetchall()
        conn.close()
        return f"Results: {results}"
```

## Best Practices

- 🔒 **Validate Inputs**: Always sanitize model inputs
- 🛑 **Graceful Error Handling**: Use structured exceptions
- 🧼 **Simple Interfaces**: Don’t over-engineer tool schemas
- 📋 **Auditability**: Log tool calls and data access

## Common Use Cases

- 🗂 **File & Document Access**: Let AI read your config/code/docs
- 📊 **Database Interrogation**: Pull insights from local databases
- 🔧 **API Bridging**: Connect to internal or external REST APIs
- 📆 **Workflow Automation**: Let Claude run jobs, add todos, update calendars
